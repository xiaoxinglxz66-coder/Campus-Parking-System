# 校园停车管理系统 (Campus Parking System)

这是一个基于前后端分离架构的校园智慧停车管理系统。

## 🛠️ 技术栈
* **后端:** Spring Boot, Spring Security, MyBatis, JPA
* **数据库:** MySQL
* **核心功能组件:** 腾讯云 OCR (用于车牌识别)
* **前端:** (这里写上你的前端技术，比如 Vue 或 React)

## ✨ 核心功能
* 车辆入库/出库自动识别计费
* 用户权限管理 (RBAC)
* 停车记录与账单查询

## 🚀 本地运行指南
1. 克隆项目到本地：`git clone git@github.com:xiaoxinglxz66-coder/Campus-Parking-System.git`
2. 导入 `campus_parking_db.sql` 还原数据库。
3. 修改后端 `application.properties` 中的数据库账号密码。
4. 启动前后端服务即可体验。
